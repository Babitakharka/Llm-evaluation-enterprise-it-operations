# LLM Evaluation for Enterprise IT Operations

A preliminary, controlled comparison of five large language models on enterprise IT operations work.

## Overview
- Models: ChatGPT, Claude, Gemini, Microsoft Copilot, Perplexity (free tiers, standard chat)
- 25 standardized scenarios across five areas: IT service management, IT operations, digital transformation, business analysis and generative AI governance
- 125 responses: each model answered every scenario once, using the same prompt in a fresh session

## Method
Identical prompt template, a fresh session per task, first response recorded, and screenshots kept as evidence. Responses were scored on six weighted criteria (accuracy, completeness, operational practicality, clarity and structure, business value, AI reasoning), out of 100.

## Results (indicative)
ChatGPT 85.3, Claude 83.4, Microsoft Copilot 82.7, Perplexity 81.4, Gemini 81.3. All five fell within about four points.

## Limitations
Scoring was rule-based and AI-assisted, with no independent human raters. Each scenario was run once, using free tiers and single-turn chat. The results are preliminary and do not show that any model is better.
